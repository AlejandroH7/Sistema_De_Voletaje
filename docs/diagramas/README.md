## Como visualizarlos en VS Code
1. Abrir cualquiera de los archivos `.md`.
2. Usar `Open Preview` o `Markdown: Open Preview to the Side`.
3. Si Mermaid no renderiza, instalar la extension **Markdown Preview Mermaid Support**.
